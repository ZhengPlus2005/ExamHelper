# ExamHelper

Windows 11 x64、C#／.NET 10＋WPF 桌面应用。仅用于学习、自测和已获允许的辅助场景，请遵守考试、招聘及平台规则。启动显示聊天主页，辅助模式采用置顶半透明窗口、悬停操作和可配置快捷键。

0.4.0 安装包输出到 D:\Code\ExamHelper\artifacts\installers\ExamHelper-Setup-0.4.0-x64.exe，相邻 .sha256 可核对散列。无需另装 .NET；便携运行须保持发布目录完整，不要只复制入口 EXE。安装完成页可选添加桌面快捷方式，“启动应用”和“添加快捷方式到桌面”默认均勾选，两行统一对齐；已有无关或被修改的同名快捷方式保留。当前用户安装不要求管理员权限。

主页可直接聊天，无需测试服务；Enter 发送，Shift＋Enter 换行，支持粘贴图片及拖入 PNG、JPEG、BMP、GIF、TIFF 文件（动态图取首帧），保存完整尺寸。图片按消息顺序显示为圆角缩略图，历史图片点击查看完整原图，可缩放、拖动、保存原始 PNG 并按 Esc 关闭。草稿图片点击主体预览，只有右上角叉号删除。每个对话独立保存草稿、模型选择和自定义标题，默认标题为“对话＋第一次发送时间”。没有消息和草稿的空对话不保留。每条消息可复制完整原始 Markdown 文字，代码块内复制只取代码；代码上方的鼠标滚轮正常滚动聊天。输入框下方最右侧“导出”可导出单文件 HTML，原图内嵌，只导出已发送消息和已收到回答，不含草稿、配置密钥或内部推理。

新安装的 AI 服务为空白，不预填供应商、地址、名称或模型。填写兼容接口后可直接在主页聊天；未完成的配置允许保存但不能调用。每个配置可维护多个模型并设置默认模型；可尝试从 /models 接口拉取，也可手填真实模型 ID。供应商未返回能力信息时不能据此认定支持图片或思考设置，可逐模型手动配置。每模型有默认思考选项；窗口里的调整仅影响该对话之后的请求，不改全局默认。切换配置加载其默认模型，切换模型加载该模型默认思考设置，现有上下文和草稿保留。接口或密钥更改使该配置全部文字和图片测试失效，修改模型名称只使该模型失效。

进入辅助模式只要求捕获保护初始化成功。辅助窗口内仅允许调用文字与图片两项测试都通过的模型，未通过的模型保留显示并置灰；语音识别未测试通过只禁用录音，不限制进入。主页聊天允许直接尝试未经测试的模型，失败显示错误，不自动重试。开始考试默认创建新对话；返回主页保留草稿和后台回答／识别，结果仍回到原对话。全应用同时只生成一条 AI 回答。失败请求、录音可手动重试或丢弃，语音成功追加后有三秒撤销入口。

辅助小窗不接受键盘文本，只由麦克风语音识别追加文字；录音最长六十秒。模型选择器悬停一秒展开及选中，移出整个区域收起。三排主操作随窗口等宽铺满。普通按钮一秒绿色进度；返回主页和隐藏为两秒红色进度，均从顶部中央沿按钮外侧顺时针绕行，移开取消。悬停图片会显示删除遮罩及红色环形进度，一秒删除。标题和右下角手柄可免点击移动／缩放；回答与草稿使用正常鼠标滚轮。新安装背景不透明度默认 50%，本版重启保留设置；文字和按钮保持清晰。

历史条目按最后一条消息创建时间倒序，显示固定 UTC＋8；纯草稿按会话创建时间，浏览、改名、保存和流式更新不改变顺序。条目悬停显示重命名和删除图标，支持批量编辑：点击条目同时预览和勾选，复选框只改变勾选；统一确认后逐条删除，失败项保留供重试。

回答在发送后立即开始计时，包含准备、等待首字和生成，运行时显示整秒，完成、失败或停止后保留一位小数；每次重试从零，隐藏、后台和系统校时不改变已用时间。生成中导出冻结当时内容及用时。

支持多屏，截图截取辅助窗口所在的整块屏幕，跨屏按最大重叠面积确定。直发仅在草稿为空且任务允许时启用，并附上配置的直发提示词；入草稿允许积累多图。辅助选择器、Markdown 和提示保持在同一受保护窗口中。捕获保护初始化失败会停留主页。AI 回答支持标题、强调、列表、表格、引用、代码块及安全 HTTP／HTTPS 链接，不执行 HTML、脚本或远程图片；用户文字按原样显示。

默认快捷键使用 Ctrl＋Alt＋F1 直发、F2 入草稿、F3 录音、F4 发送、F6 清空、F7 新对话、F8 停止、F9 隐藏／显示、F10 折叠／展开、F11 返回主页，以及 Ctrl＋Alt＋Z 撤销语音。没有独立 F12 隐藏绑定，F9 隐藏／显示保留。隐藏仅影响显示，任务与快捷键继续运行。点击主页“×”收起到托盘；单击托盘恢复，右键“结束进程”正常保存后退出，保存失败保持运行并允许重试。

关闭设置时未保存修改会询问保存、放弃或取消。预置提示词防抖自动保存，其他设置以保存操作为准。密钥按 Windows 当前用户加密；保存失败保留原配置。0.4 系列的设置、历史和原图独立保存在 %LOCALAPPDATA%\ExamHelper\0.4，默认程序目录为 %LOCALAPPDATA%\Programs\ExamHelper-0.4。首次为空白，不读取、迁移或删除旧系列数据；本版重启恢复本版资料。删除历史会清理不再被引用的图片。

开发使用 global.json 锁定的 .NET 10 SDK。scripts/Test.ps1 -Configuration Release -DotnetPath <dotnet.exe> 执行锁定恢复、完整构建和测试；scripts/Publish.ps1 -Version 0.4.0 发布自包含程序；scripts/Build-Installer.ps1 -Version 0.4.0 -IsccPath <ISCC.exe> 生成安装器。build-info.json 记录准确提交和依赖散列。第三方许可见 THIRD-PARTY-NOTICES.md 及 packaging/licenses/。

tools/ExamHelper.InteractionLab 是不随安装器分发的验证工具；受控模式只保存自有合成参考画面。验证范围和限制见 docs/verification/revision-0.4.0.md。此前用户已验收 Windows 自带截图／录屏和 Chrome 屏幕共享；OBS、腾讯会议及其他捕获后端仍不作未经验证的保证。
