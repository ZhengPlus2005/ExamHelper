# Windows 核心交互验证

环境：Windows 11 x64，build 26200，.NET SDK 10.0.402／runtime 10.0.13，当前屏幕 125%（120 DPI）。

## 2026-10-17 需求修订与结果

用户实测确认旧输入框虽然显示光标，但 Windows 拒绝后台激活；点击才可输入。用户决定取消全部键盘文字输入，仅通过语音输入文字。本次删除悬停聚焦、取消输入、英文输入法切换及状态恢复；草稿改为不可聚焦的只读 TextBlock，窗口拒绝鼠标激活。主页和设置仍使用正常点击与键盘操作。

先增加回归测试，旧实现出现两项失败（缺少只读预览、仍注册取消输入快捷键）；修改后 Release 自动测试 25 项全部通过（Core 13、Windows 12），零失败、零跳过。删除 8 项已取消功能的专用测试，增加 3 项语音专用草稿回归；覆盖实际窗口预览不可聚焦、模拟语音追加与清空、无取消按钮、原生鼠标激活消息及快捷键映射。原 Ctrl+Alt+F5 留空，其他默认快捷键保持原编号。

更新后的自包含 EXE 原生验证 9 项全通过：默认快捷键注册、真实系统冲突、隐藏时保留注册、释放后重新注册、临时 Esc 注册／释放、草稿不可获得键盘焦点、无聚焦悬停命令、拒绝鼠标激活。此次不再包含已取消的输入法／焦点恢复检查；没有通过绕过 Windows 前台限制来修复旧输入行为。

## 运行方式与限制

自包含验证 EXE：D:\Code\ExamHelper\artifacts\windows-core\ExamHelper.InteractionLab.exe。保持同目录依赖文件一起使用，无需另装运行时。本阶段不是正式安装版，也没有麦克风录音或云端语音识别；“模拟语音追加”只验证识别结果写入草稿的交互。

运行 ExamHelper.InteractionLab.exe --verify D:\Code\ExamHelper\artifacts\windows-core-check 可重复受控捕获及原生检查，只创建自身测试窗口。Ctrl+Alt+F9 隐藏／恢复，Ctrl+Alt+F12 退出；悬停退出等两秒。其他快捷键仅演示命令，不实际上传截图或录音。

## 仍需实际手势验证

自动化工具没有纯鼠标移动／悬停接口，因此不宣称真实手势完成。需在当前屏幕手动执行：

1. 悬停“一秒触发测试”：一秒触发一次，停留不重复；移开再进入可再次触发，退出需两秒。
2. 悬停标题一秒后移动，包括移出原窗口；停稳一秒固定。右下角同样验证缩放；操作期间其他悬停不触发，Esc 固定。
3. 滚动滑块悬停一秒后上下移动，横向离开仍跟随；停稳固定后保持鼠标位置不会再次激活。
4. 在记事本或浏览器输入区工作，移入小窗按钮与草稿预览不应抢键盘焦点；预览不出现可编辑光标，键盘不能修改文字。“模拟语音追加”追加中文，清空按钮清除草稿。实际录音／ASR 在后续任务实现。
5. 隐藏再恢复后快捷键仍有效；关闭实验程序后快捷键释放。

历史审查修复了悬停首次进入被抑制、只读进度绑定和滑块离开即禁用问题；旧 IMM 恢复路径随本次需求删除。Minor 暂缓：HoverScrollBehavior 的 Loaded 重复订阅需在产品阶段视图复用时补齐对称解绑，当前单次创建实验窗不重复加载。
