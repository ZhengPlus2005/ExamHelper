## 执行中的裁定

使用 PowerShell 7 运行 UTF-8 脚本，代价是旧版 PowerShell 的测试运行兼容性；忙碌拒绝且未发起的服务测试保留既有资格，代价是等实际重测才更新；截图直发准备失败保留普通图片草稿，代价是需发送或清空后再直发；已提交删除的资源释放失败单独记录，代价是需退出或清理重试而非恢复已删记录；粘贴命令查询不读取剪贴板，空剪贴板可能显示可用但执行无操作；开始菜单命名为 ExamHelper 0.4 避免覆盖旧系列，代价是显示版本后缀。最终审查产生的裁定和延期项另记于发布记录。
