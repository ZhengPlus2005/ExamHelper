# 0.2.0 修订验证

本版对应用户明确要求的九项修改，继续已授权的当前会话顺序开发，不重复要求确认相同需求。设计与实施记录见 docs/superpowers/ 下的 2026-10-17 文档。原有 0.1.0 记录保留；本文件优先描述本版状态。

九项实现分别是：未保存关闭确认；不透明度百分比与合成答题双层预览；可新增、删除、启用及独立测试的 AI 配置目录；同一保护窗口中的快捷键提示、红色两秒主页／隐藏按钮；按所属显示器进行物理像素全屏截图；实际录音样本映射的音量条；普通鼠标滚轮；白底圆角铅笔图标；安装完成页可选桌面快捷方式。预览不分发用户完整浏览器截图，图标由原生矢量生成七种 ICO 尺寸，未引入新依赖。

## 自动与本机验证

Release 锁定依赖恢复、完整构建及回归结果以 final-validation.log 为准：176 项（Core75、Windows101），零失败、零跳过，构建零警告、零错误。新测试覆盖配置选择与密钥隔离、测试时删除／修改配置、未保存关闭策略及真实 WPF 关闭事件、保存中继续编辑、失败保存保留旧凭据、测试等待关闭确认、预览和音量绑定、提示与滚轮、截图所属屏、负坐标及跨 DPI 尺寸。

本机实际连接两屏：左屏 (-2880,5) 的 2880×1800、200%，主屏 (0,0) 的 2560×1440、125%。以产品相同 PerMonitorV2 清单运行同一个正式 OverlayWindow，先显示开发程序自己的纯绿参考窗口，再在两个屏幕上分别定位小窗、按 owner HWND 全屏捕获。捕获尺寸与目标屏一致，小窗均从受控截图排除，1200×1000 物理尺寸恢复一致，无网络上传。只在所有像素为已知纯绿色时保存证据，没有保存其他应用画面。跨 DPI 回归在旧实现在实际硬件上先失败（1200×1000 变成1920×1600），分两步移动和调整后通过；目标屏最小尺寸在该屏 DPI 下计算。

麦克风实际采样约3.24秒，峰值0.0131，显示值约0.372，读到非零音量，采样16000Hz／16bit／单声道，临时录音已删除、上传0。原有正式保护窗口的受控 GDI 比较差异0，保护读回0x11，九项原生检查通过。图标从发布 EXE 提取并查看，设置页面、35%／55%／85%预览和音量条的 WPF 渲染已检查。

## 独立审查与本轮修复

独立只读完整增量审查范围为6148498..9de826d，发现五项 Important、一项 Minor，无确定 Critical。按 executing-plans 进行一次必要修复，不反复重审。

| 审查问题 | 处理与证据 |
| --- | --- |
| 保存等待中换密钥导致旧请求给新密钥记通过 | 请求、配置摘要、凭据一并冻结；结果只属于实际使用的快照；HTTP及存储等待点回归 |
| 单独测试隐式保存整个表单，其他无效草稿阻止测试 | 只提交被测试配置和证据；其他草稿保持未保存；关闭询问期间等待用户决策，放弃后不再写入迟到结果 |
| 配置保存失败仍覆盖原密钥 | 新密钥先写新身份，JSON成功后才切换引用；失败只清理未引用的暂存凭据；原配置始终可用 |
| 保存并返回绕开保存期间的新修改 | 重新进入统一关闭策略；真实 WPF 等待保存期间编辑的回归覆盖 |
| 卸载删除无关同名桌面快捷方式 | 记录本安装器写入的 SHA-256，创建时保护冲突，卸载仅删除归属且未改变的文件；实际编译的 Pascal 探针覆盖无归属保留、修改后保留、自己未改的链接删除 |
| Minor：删除凭据失败后丢失重试身份 | 与凭据事务合并，失败身份留在清理队列，下次保存重试；持续存储故障或进程退出后可能保留未引用的加密文件，不影响当前配置 |

审查未确定的跨 DPI 风险已通过真实双屏复现并在同轮修复。其他已拒绝或延后的推断不算通过的测试；没有更改系统显示布局和缩放。
