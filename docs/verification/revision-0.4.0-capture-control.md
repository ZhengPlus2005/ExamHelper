# 0.4.0 同版本更新：设置布局与捕获开关

用户要求移除设置页全局 AI／语音验证汇总；AI 服务测试输出仅在 AI 页底部显示；语音页最后两个测试按钮上方显示语音验证状态；在快捷键左侧增加“控制”标签页及反屏幕捕获开关，关闭时仍可进入辅助模式。仅重建本地安装包，版本号保持 0.4.0。

开关持久化于 Ui.CaptureProtectionEnabled，默认 true；已有设置缺少字段时沿用开启。修改后保存并在下次进入辅助模式生效。窗口创建、显示前复核及重建按此设置调用 SetWindowDisplayAffinity 并回读：开启为 0x11，关闭为 WDA_NONE（0）。置顶、免焦点操作、热键与截图流程保持可用。控制页仅显示开关名称，使用说明解释保存和生效方式。

删除 VerificationSummary 及其全局绑定。AI 的 ResultText 输出移入 AI 标签页底部；语音识别使用独立 SpeechResultText 输出，避免覆盖 AI 测试结果。语音是否验证使用当前语音地址、模型、密钥及麦克风计算，修改相关字段立即刷新；计算不依赖未完成的 AI 配置草稿。无效语音地址显示未验证，不使绑定变空。未验证仍只禁用辅助录音。

## 自动化与原生验证

5 项新增测试最初 4 失败、1 通过，失败分别复现全局汇总仍存在、无控制页、无语音状态和关闭后仍使用 affinity 17。修改后 5 项通过。完整脚本 Test.ps1（锁定依赖恢复、Release 构建与全套测试）通过 362 项：125 Core、237 Windows，零失败、跳过、构建警告或错误。TRX 结果目录为 artifacts/test-results/86fbb608dc764778b24dfc13efefbb20。

Windows 11 build 26200、125% DPI 下用开发工具 --verify-capture-control 实测自有参考场景：开启时读回 17，GDI 捕获前后变化 0 字节；关闭时读回 0，变化 1,776,907 字节，验证小窗实际可见。两种模式均通过 13 项原生交互检查，含热键、隐藏恢复、免焦点与菜单同 HWND。参考截图仅来自测试工具自己的窗口，未向云端发送。

设置页 AI、语音和控制标签的自有数据渲染预览已人工检查。AI 输出只在 AI 页，语音状态位于最后两个按钮上方，控制页位于快捷键左侧。完整日志、截图与原生结果位于 D:/Code/ExamHelper/artifacts/0.4-control-revision-check。
