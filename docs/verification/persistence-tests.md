# 持久化验证

2026-10-17 完整 Release 回归 98 项通过（Core47 Windows51）。SQLite 真实文件事务往返保存文字、原图引用、未发草稿、冻结请求参数及部分回答；数据库设为只读后保存失败返回 Storage，旧快照不变。启动恢复将 Pending／Generating 转为失败待处理状态并保留部分回答和新草稿，清除语音状态与过期交互标记。

图片引用测试验证跨对话共享文件：删除一个会话后其他引用仍有效，全部引用移除后清理文件。清理失败可重试。图片仓库先原子保存文件，数据库保存引用；孤图清理仅在启动或主页空闲删除后运行，不能与尚未写入首个数据库引用的截图并发。TempAudio 清理只处理本目录的已知 GUID WAV 文件，不递归删除目录，不清理任意用户文件。诊断只记事件枚举、错误分类和数值错误码，不记自由文本、密钥、题目、识别或图片。
