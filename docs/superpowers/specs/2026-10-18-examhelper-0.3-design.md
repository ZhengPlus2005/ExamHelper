# ExamHelper 0.3.0 设计方案（最终确认稿）

日期：2026-10-18。基础版本0.2.0，提交9cb6c044f6f7165f957caa186fafcf658f0655c1。拟定发布版本0.3.0，产品代码尚未修改。按用户要求，设计与实施计划一并供最后一次开工确认，确认后沿用当前会话顺序实施。

## 1. 目标和边界

保留Windows11 x64、当前用户安装、C#／.NET10＋WPF、语音辅助小窗与捕获保护，将主页升级为可直接聊天的历史工作区，加入每配置多模型、思考选项、完整图片消息、Markdown、HTML导出和系统托盘。主窗口常规点击及键盘操作；辅助小窗免点击、不抢焦点。

此前“退出时把未发送草稿追加到聊天末尾”的方案已经撤销。草稿独立归属于各对话，保存后恢复到主页输入框，不伪造为已发送消息。

## 2. 辅助窗口

仅移除独立F12“隐藏小窗”快捷键及对应设置项，保留F9“隐藏／显示”和“隐藏”按钮。迁移按命令身份移除旧绑定，不能误删赋给其他功能的F12组合。新安装背景不透明度默认50%；已有安装保留原值，文字和按钮不跟随背景变淡。

移除标题栏右侧“悬停操作 · 主页／隐藏两秒”。展开时按钮显示“折叠”，折叠后显示“展开”。

“截图直发”“截图入草稿”“开始录音／停止录音”移到输入区域下方，排在“清空输入”之前，随后为“发送”。窄窗口允许换行，回答很长时仍能访问草稿和发送按钮。

移除图片下“悬停删除”文案。进入待发送图片时叠灰色遮罩，中央白色圆圈及叉号，外圈红色环形进度在1秒内增长，完成后删除。离开取消复位，一次进入只触发一次，下一张图片移动到原指针位置不能连删；移动／缩放窗口时不触发。

主页／隐藏按钮继续2秒红色进度，其余普通按钮1秒绿色进度。保留原有语音撤销、最长60秒、失败重试及所属显示器全屏截图；小窗不接受键盘文本编辑。截图直发的预置提示词仍只用于直发。

## 3. 配置、模型和思考

设置页移除“服务类型”。每配置保留名称、API地址、密钥，内部进行兼容适配。每配置可添加多个真实模型ID，必须指定一个默认模型。

提供接口拉取及手动新增、删除入口。拉取用该配置当时的地址和密钥，用户勾选所需结果加入，不自动全部导入或启用。失败显示错误，仍能手动填写；迟到结果不能写到另一个配置。删除默认模型时，保存前须指定另一个默认模型。

每模型独立保存默认思考设置，新增模型初始“服务默认值”。按实际能力提供思考开关或合法强度档位。手工覆盖优先，其次明确返回的元数据／已适配模型规则；不能确定时只用服务默认，不附加思考参数。允许设置页手动指定支持类型、请求方式和档位，不能混用不同协议的开关和强度参数。

当前官方资料：Kimi K3使用reasoning_effort的low／high／max，K2.6使用thinking.type的enabled／disabled。Kimi模型列表返回supports_reasoning等标志，不等于列出全部档位；DeepSeek可返回effort.supported_levels。只针对实际已确认能力提供选项。

思考设置控制请求参数，用户界面显示最终回答。供应商要求多轮回传的reasoning_content等信息内部保存和传递，不作为额外答案展示或写入HTML正文。

## 4. 选择和验证

主窗口常规点击选择配置、模型和思考；小窗悬停入口1秒展开、悬停选项1秒选中，选中或移出整个选择区域后收起。列表在同一个受保护HWND内绘制，不使用独立Popup，不转移答题界面的键盘焦点。

切配置保留上下文及草稿，加载该配置默认模型；切模型加载其默认思考设置，切回来也重新加载默认值。后续请求用新选择，已启动回答用原始参数及凭据快照。手动重试视为后续调用，使用当前选择、原问题内容。

每段对话保存当前配置ID、模型ID和思考选择，切换历史或重启恢复。恢复保存选择不是手动切换，不重新重置思考值。新对话加载设置中的启用配置、默认模型及默认思考。运行时调整不覆盖设置默认。

主窗口聊天不要求任何测试，填写实际调用配置后即可发送；失败显示HTTP状态码／服务错误码和可读信息，保留内容供手动处理，不自动重试。

辅助模式只可选择图片测试通过的模型；开始考试还须语音验证通过。资格按配置及模型分别保存：地址／密钥变更使该配置全部失效，修改模型ID只使该模型失效，换思考档位不逐档重测。测试只保存所测项和证据，不隐式保存其他表单修改或启用配置。

历史引用的配置／模型被删除后保留历史、草稿和原名称，提示不可用，由用户重选后发送，不能静默换服务。配置变化不打断已启动调用。

## 5. 主窗口聊天

移除“继续此对话”和从历史进入辅助窗口的入口。增加“新对话”，直接在主页聊天；“开始考试”始终新建独立辅助对话，不带入当前主页的历史和草稿。旧对话在主页继续。

历史消息下方增加多行输入框、待发送图片及配置／模型／思考选择。Enter发送，Shift＋Enter换行；中文输入法选词的Enter不能误发送。支持正常中英文输入、粘贴图片和拖拽本地图片，图片只进草稿，不自动发送，待发送图片可点击删除。

每段对话独立保存文字、图片草稿和模型选择。切换历史前保存原草稿，切换后恢复目标草稿，重启可恢复。异步导图和识别结果必须写回发起时的对话，不能跟随当前选择。保存失败提示并保留内存内容，不悄悄丢弃。

全软件同时只生成一个AI回答，不排队自动发送。切到B时A在后台继续，B可浏览和编辑草稿，A结束或手动停止后才能再发送。设置中的AI文字／图片测试也遵守同一生成限制，拉取模型列表不占用生成任务。发送时冻结当前内容并清出对应草稿，后准备的内容不能被迟到成功／失败覆盖。

图片导入采用系统可解码的常见位图，首批保证PNG、JPEG、BMP、GIF首帧、TIFF首页，统一保存完整像素PNG。不支持的格式提示错误而不破坏其他草稿。维持已有请求体积与错误处理规则，不擅自缩小原图。

## 6. 托盘、返回主页和退出

| 操作 | 结果 |
| --- | --- |
| 主窗口“×” | 收起到托盘，任务继续，进程不退出 |
| 主页时单击托盘 | 恢复显示主窗口 |
| 辅助模式时单击托盘 | 等同返回主页，关闭小窗、主页选中原对话并恢复草稿 |
| 返回主页 | AI继续并在主页显示；录音自动停止提交识别，正在识别继续，结果加入原对话草稿，不自动发送 |
| 小窗隐藏／折叠 | 仅改变显示，任务继续，草稿不转消息 |
| 托盘右键“结束进程” | 正常退出：取消AI／录音／识别，保存已收到回答、各对话草稿和选择，再结束进程 |

启动即显示系统托盘图标。退出保存失败则保留进程和托盘，提示重试；再次退出可重新保存。已收到部分回答按已停止保存，未完成录音／识别不等待转文字。设置未保存确认和现有存储保护仍适用。

返回主页不等待识别网络请求结束才显示主页。待重试录音在主页也有重试／丢弃入口，避免关闭小窗后无法处理。

只有消息为空且文字／图片草稿均为空时不保存对话；未发送草稿、失败消息和部分回答均保留。空白打开再退出辅助模式不留历史。收起主页到托盘不等于退出。

## 7. 标题和图片消息

默认标题“对话 yyyy-MM-dd HH:mm:ss”，取第一次发起发送的本地时间，后续发送和重试不改变。未发送时“对话（未发送）”，首次发送后生成时间标题。

历史可手动重命名，持久保存，不被后续发送覆盖。移除“保留草稿：true／false”这一行。

消息按时间排序，图片属于具体消息，位于该条文字上方，多图按发送顺序。主页图片为圆角矩形缩略图，点击打开原图，默认适应大小，可滚轮缩放、拖动平移、Esc关闭。小窗待发送缩略图保留悬停删除，不增加点击放大。完整原图继续保存，删除历史时清理不再引用的图片。

## 8. Markdown与HTML导出

主窗口和小窗的AI回答统一支持标题、粗体／斜体、列表、引用、表格、链接、代码块和语法高亮，代码可复制；用户消息按原始文本保留。流式回答持续更新，未闭合围栏能稳定显示，用户向上翻看时不强制拉回底部。

不加入数学公式、Mermaid、原始HTML和远程图片加载。未知代码语言显示等宽原文，不假装高亮；链接不因悬停自动打开，也不能触发执行内容。

导出当前选中对话的标题、消息时间、正文及所属图片，保留Markdown排版，图片全部用data URI内嵌，样式内嵌，生成单个可离线查看的HTML。不导出未发送草稿、API密钥或内部配置。导出冻结当时快照，生成中的回答只含已收到部分，不改变原记录或移动源图片。

## 9. 说明和图标

主页“设置”左侧增加“使用说明”，解释两个聊天模式、测试门槛差异、模型／思考、截图录音悬停、草稿、快捷键、托盘、图片查看及导出。

包含：“本软件仅供学习、练习及获得授权的辅助使用。请遵守所在场景的规则，不在禁止使用外部辅助工具的考试或考核中使用。AI输出可能存在错误，应自行核实。”在说明里展示，不新增首次启动强制勾选。

用本轮附图完整替换图标，保持比例，不重画或裁主体；生成窗口、EXE、托盘、安装器所需PNG及多尺寸ICO。源图为codex-clipboard-8e5d13d8-fdce-4d17-a56f-79cf21f13d30.png。

## 10. 架构选择

推荐“每对话独立运行时＋应用级单生成门”，保持Core／Windows／WPF分层。ConversationWorkspace按需持有各段SessionCoordinator，选中对话只改变视图；每段独立草稿、请求、语音上下文和临时录音，物理录音同一时刻只采集一次，停止采集后的后台识别独立管理。AiGenerationGate限制整个应用只有一个AI生成。后台回写校验SessionId／RequestId／代次，不依赖当前选中或辅助模式是否显示。

继续使用一个可切换状态的Coordinator，表面改动较少，但A后台生成与B编辑容易串写；每对话并行生成则不符合已确认单生成规则，增加复杂度。因此不采用这两个方案。

AppLifecycle统一托盘、收起、恢复、返回主页和保存后退出。Windows层负责模型发现、请求凭据冻结、图片导入和持久化，UI分发命令并显示状态；按职责拆分文件。

Markdown使用Markdig1.4.1解析，WPF原生内容展示；AvalonEdit6.3.1.120仅用于非可视代码着色，不把可编辑TextEditor嵌入小窗。HTML共享语法规则。不引入WebView2。依赖及锁文件在最终确认后才添加。

## 11. 迁移与保护

设置格式升为3：旧每配置单模型导入为一项，保留配置、密钥身份及启用项。原资格只有旧指纹有效才迁入原模型，新增模型不获得资格。导入的旧K2.6明确禁用思考行为映射“关闭”，新增模型初始“服务默认”。删除独立隐藏绑定，保留F9和其他自定义项。

已有不透明度原值保留；旧文件省略该字段时按旧默认85%解释，新安装才为50%。

快照增加手工标题、首发时间、模型选择及供应商多轮必要响应字段。SQLite事务迁移前做一致性备份，更新数据库版本后旧程序应拒绝写入不认识的版本。保留全部旧消息、草稿、图片引用和请求恢复信息，首发时间从第一条用户消息恢复。旧历史未保存的推理字段不能伪造；兼容错误如实显示，不能偷偷丢上下文。

保留0.2的凭据分阶段写入／JSON原子提交。测试、拉取及已启动请求绑定原快照，不给后来改动的内容记通过。持久化及内存草稿、后台任务、待提交导入图片的引用均纳入清理保护。

## 12. 验收和开工确认

确认后沿用当前会话顺序实施，必要行为先失败回归再实现，任务分别提交。验证用临时配置、假HTTP、自有图片，不读取真实密钥或历史，不进行付费调用。

重点验证跨对话AI／语音不串写，主页零测试门槛与辅助门槛差异，默认值与对话选择互不覆盖，参数／凭据不可变，草稿重启恢复，标题不回滚，空记录过滤，迁移失败保护，异步粘贴拖放，中文输入法Enter，HTML离线和小窗同HWND保护、不抢焦点，以及托盘保存失败不退出。

生成0.3.0当前用户x64自包含安装器、SHA-256、源码ZIP和交付说明，保留旧包。人工／硬件验收按真实证据记录，不把编译代替交互验收。0.2的历史176项结果不能代替0.3测试。
