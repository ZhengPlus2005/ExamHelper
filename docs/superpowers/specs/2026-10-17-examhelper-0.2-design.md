# 0.2.0 需求修订设计

依据用户在 0.1.0 配置 API 后报告功能正常，以及随后明确要求的九项变更。本次为现有产品的修订，沿用当前会话顺序实施，不改变已接受的历史、语音专用草稿、服务资格、原图、保护先于显示与失败手动重试规则。用户提供的九项是本次变更授权和验收基准。

1. 设置关闭：所有可编辑内容均比较最近成功保存快照；未保存时，“保存／不保存／取消”对话框覆盖关闭按钮和窗口 X。保存失败留在设置；没有修改直接关闭。待防抖提示词也属于未保存内容，修复旧版已知问题。
2. 不透明度：仍为背景 35%～100%，滑块右侧实时百分比，下方合成双层预览复现附图 1 的白色题面／代码区域，覆盖本软件深色辅助窗；只改变软件背景，不让文字一起透明。不打包用户浏览器截图与账户信息。
3. AI 配置：新增可命名的配置列表，每项包含类型、地址、模型、独立加密密钥与图片测试证据。可添加／删除／启用；同时仅启用一项。选中仅供编辑／测试，不自动启用。每项可分别文字／图片测试，测试其他配置不改变启用项；配置变更失效自身资格。允许删除最后一项，提供空状态；没有启用且已验证的配置不能开始。升级导入旧 AI 项和证据，保留旧 SecretId，不重新读取／迁移真实用户文件来代替测试。
4. 小窗：新增提示按钮，1 秒悬停后在同一 HWND 内显示实际快捷键，离开按钮马上关闭，不使用普通 Popup／ToolTip 窗口。返回主页和隐藏均 2 秒，红色进度，其他按钮绿色。替换原退出按钮为隐藏；默认 Ctrl+Alt+F12 改为隐藏，Ctrl+Alt+F9 继续隐藏／恢复；原退出枚举保持已有数字以兼容序列化，新的 HideOverlay 追加，不重编号。主页保留软件退出途径，Alt+F4 仍走原正常退出生命周期。
5. 多屏：按辅助窗口 HWND 最大相交／最近显示器选择整个物理屏幕，不按鼠标所在屏，不合并多屏，不缩图。隐藏窗也可按其位置截图。窗口可跨屏移动，物理像素采样避免跨不同 DPI 的拖动跳变；停稳后收拢到最近工作区。新增可选物理位置快照；老版位置可读取，拔屏后恢复到最近现有屏。没有定位窗口且有多屏时明确失败，避免截错屏。
6. 音量：从采集到的 PCM／float 样本计算峰值（含 WAVEFORMATEXTENSIBLE），按 dB 映射到 0～100% 可见刻度，静音归零、停录归零，避免原设备全局 meter 不响应。刷新 100ms，不写音频额外副本，不改变单声道编码链。
7. 移除产品小窗内全部悬停滚动，包括答案、截图、语音草稿、状态；滚轮在指针下的滚动区正常工作，内容短时向外冒泡。移动／缩放仍为原悬停交互。
8. 图标：代码原生矢量源，白色圆角矩形、中央深色铅笔；参照附图 2，不复制其文件内容到历史。生成多尺寸 ICO 和 PNG，统一用于应用窗口／EXE／安装包／快捷方式。
9. 安装：版本 0.2.0，保持 AppId 以支持升级、当前用户无管理员。完成页增加默认不选的“添加桌面快捷方式”，完成后才创建当前用户 .lnk；静默安装不创建。卸载删除自身快捷方式但保留历史和设置。

验证使用临时数据、合成 UI 和假 HTTP；不读取／覆盖用户真实设置、不调用用户 API。保留 0.1.0 安装器以便对比。新安装器本地重建、自包含自检，源代码与兼容记录一起交付；实际多屏／不同 DPI 和真实音量体验只在可用硬件范围内报告。
